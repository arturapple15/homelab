# HomeLab Infrastructure as Code (IaC)

Репозиторий для декларативного управления домашней лабораторией на базе Ubuntu Server 24.04 LTS с использованием Docker и Docker Compose. Проект построен на микросервисной архитектуре (каждый сервис изолирован в своей директории).


## Архитектура и стек сервисов

### 1. Игровой сервер (Minecraft Forge)
* Оптимизированный контейнер на базе образа `itzg/minecraft-server` с поддержкой модификаций (Forge 1.20.1).
* Безопасность и управление: Доступ строго ограничен через встроенный белый список (whitelist). Сетевой порт голосового чата (Simple Voice Chat) изолирован и проброшен отдельно по протоколу UDP (24454). Конфигурационные файлы и данные вынесены на хост через переменные окружения (`.env`) для обеспечения персистентности данных.

### 2. Сетевое хранилище (Samba NAS)
* Предоставляет файловый доступ к дисковому пространству мини-ПК для устройств в локальной сети по протоколу SMB/CIFS с разграничением прав доступа.

### 3. Коммуникационный стек (Matrix & Coturn)
* Matrix Synapse — приватный сервер коммуникаций. Конфигурация развернута в режиме закрытой регистрации и отключенной федерации для максимальной конфиденциальности.
* Coturn TURN/STUN Server — VoIP-сервер для обеспечения WebRTC-звонков клиентов Matrix. Запущен в режиме `network_mode: host` для исключения накладных расходов Docker-NAT при обработке динамического пула UDP-портов.

## Инструкция по развертыванию (Deployment)

### 1. Инициализация сети
Перед запуском контейнеров необходимо создать общую виртуальную сеть Docker:
```bash
docker network create homelab_net
```

### 2. Запуск сервиса (на примере Minecraft)
```bash
cd services/minecraft
docker compose up -d
```

## 🔒 Безопасность проекта (Best Practices)
* Secret Management: Файлы конфигурации полностью очищены от чувствительных данных. Пароли, токены, тома данных (`**/data/`) и локальные файлы сред (`.env`) занесены в `.gitignore`.
